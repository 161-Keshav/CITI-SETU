# Roadmap

1. Build the full seeded, ring-structured simulator and visible per-bank graph views.
2. Train SageLite, isolated, federated, and centralized arms; measure fairness, latency, privacy-utility, and poisoning resilience.
3. Replace the local policy with an exported ONNX model and a real feature store.
4. Add formal secure aggregation, stronger identity controls, rate limits, and monitored audit storage.
5. Run a shadow-mode pilot only with a participating bank, then seek NPCI-style sandbox access. Review Hindi, Tamil, and Telugu copy with native speakers before any user study.
